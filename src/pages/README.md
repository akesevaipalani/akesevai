# Public Pages

The page manifest in `src/data/pageManifest.js` maps each public website section to its intended page module:

- Home
- About Us
- Services
- Weblink
- Photo Maker
- Forms
- Current Notifications
- Software
- WhatsApp Poster
- Contact Us

The current implementation keeps the shared UI in `App.jsx` while the page ownership map is ready for further component extraction.
